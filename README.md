# Менеджер личных задач

Версия Python: 3.11.9

## Установка и активация окружения

Windows:

``` powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

## Запуск:

```bash
python -m taskman            # пустой список
python -m taskman --demo     # запуск с демонстрационным набором из шести задач
python -m taskman --help     # справка по ключам, меню не запускается
```


## Структура:

```
taskman/
    __init__.py     докстринг кода
    __main__.py     точка входа:  --help, запуск run_menu()
    menu.py         цикл главного меню и функции команд cmd_*
    storage.py      операции над списком задач (без print/input)
    io_utils.py     диалог с пользователем и форматирование (без данных)
    validators.py   проверки полей: (признак успеха, причина отказа)
    demo_data.py    get_demo_tasks() - новый список при каждом вызове
```

Зависимости односторонние: `menu` знает о `storage`, `io_utils` и `validators`. Модули данных (`storage`, `validators`, `demo_data`) не
общаются с пользователем.

## Схема данных

```python
Task = Dict[str, object]
TaskList = List[Task]

task: Task = {
    'id': 1,                 # int, выдаётся программой, уникален в сеансе
    'title': 'Купить хлеб',  # str, 1-60 символов
    'priority': 3,           # int, от 1 до 5
    'due': '2026-09-01',     # str, формат ГГГГ-ММ-ДД
    'done': False,           # bool
}
```

Идентификатор задачи - на единицу больше наибольшего существующего, для пустого
списка - единица. Освободившиеся идентификаторы не переиспользуются. Все команды,
работающие с конкретной задачей, принимают идентификатор, а не позицию в списке.

## Известные ограничения

- Данные живут только в оперативной памяти в течение одного запуска и не сохраняются
  на диск - работа с файлами не входит в объём этого задания.
- Регулярные выражения и классы сознательно не используются.
- Расширения из раздела 5 задания (группировка, отмена действий, ключи `--sort`/
  `--filter` и т.д.) не реализованы в этой версии.
